# Консольная игра "Угадай число"

## Вариант 1

Консольная игра на угадывание числа.

Компьютер загадывает число **27** в диапазоне от **1 до 50**.
Игроку даётся **6 попыток**, чтобы угадать загаданное число.

## Правила игры

1. Загадано число от 1 до 50.
2. У игрока есть 6 попыток.
3. После каждого неправильного ответа программа сообщает:

   * `больше` - если загаданное число больше введённого;
   * `меньше` - если загаданное число меньше введённого.
4. Если игрок угадывает число, он побеждает.
5. Если все 6 попыток использованы и число не угадано, игрок проигрывает.
6. Число вне диапазона от 1 до 50 не расходует попытку.
7. При вводе нецелого значения программа просит повторить ввод.

## Запуск

Для запуска игры необходимо:
0. python game.py
1. Открыть файл `game.py`.
2. Запустить программу.
3. В главном меню выбрать:

   * `1` - начать игру;
   * `2` - посмотреть правила;
   * `3` - выйти из программы.

После завершения игры управление возвращается в главное меню.

## Реализованные функции

* `read_guess()` - запрашивает число от 1 до 50 и повторяет ввод до корректного значения.
* `compare_guess(guess, secret)` - сравнивает введённое и загаданное числа.
* `show_attempts(left)` - показывает количество оставшихся попыток.
* `play_game()` - запускает одну партию и обрабатывает игровые ходы.
* `show_rules()` - выводит правила игры.
* `read_choice(prompt, allowed)` - проверяет выбор пункта меню.
* `main()` - организует главное меню и запуск игры.

## Проверки

### Проверка 1 - угадывание числа

Введено:

```text
27
```

Результат:

```text
угадал
Победа!
```

**Ожидаемый результат:** игрок побеждает.

### Проверка 2 - загаданное число больше

Загаданное число:

```text
27
```

Введено:

```text
20
```

Результат:

```text
больше
```

**Ожидаемый результат:** программа сообщает, что загаданное число больше.

### Проверка 3 - загаданное число меньше

Загаданное число:

```text
27
```

Введено:

```text
35
```

Результат:

```text
меньше
```

**Ожидаемый результат:** программа сообщает, что загаданное число меньше.

### Проверка 4 - некорректный ввод

Введено:

```text
abc
```

Результат:

```text
Введите целое число
```

После этого программа снова запрашивает число.

**Ожидаемый результат:** некорректный ввод не завершает программу и не расходует попытку.

### Проверка 5 - число вне диапазона

Введено:

```text
100
```

Программа снова показывает:

```text
Введите число от 1 до 50:
```

**Ожидаемый результат:** значение вне диапазона не принимается и не расходует попытку.

### Проверка 6 - поражение

Игрок использует все 6 попыток, не угадав число `27`.

Результат:

```text
Поражение. Вы не угадали число.
```

**Ожидаемый результат:** после шести неправильных попыток игра заканчивается поражением.
